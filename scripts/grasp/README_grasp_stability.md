# 가상 파지 요동 진단

접기 실험은 중단하고 집기 → 8cm 들기 → 10초 정지 유지 → 내리기 → 놓기만 검증합니다.
30cm 천, 1.5×0.9m 테이블을 사용합니다. 현재 기본값은 메시 refinement 32, 두께 3mm입니다.
직전 부드러운 천의 면적당 질량과 막 강성을 유지하도록 Young 탄성계수는 약 66666.67,
체적 밀도는 약 333.33kg/m³로 설정했습니다. 굽힘 강성 계수는 두께 보정 후의 말림을
줄이기 위해 약 185.19로 더 낮췄습니다.
수건 섬유 텍스처와 두께가 있는 표시 메시도 적용합니다.

## 원인 후보와 변경

기존 `a_single_point_picker.py`의 표면 천 구현은 물리 스텝 뒤 선택 정점의 위치와
속도를 덮어씁니다. 따라서 보정 후 파지점 오차 0만으로는 안정성을 입증할 수 없습니다.
과거 집기 예제에서도 보정 전 오차와 내부 속도가 높았으므로 접기 이전부터 남아 있던 문제입니다.

`virtual_attachment_picker.py`는 단일 정점을 `OmniPhysicsVtxXformAttachment`로
물리 솔버 안에서 연결합니다. 정점 위치·속도 배열을 매 스텝 덮어쓰지 않습니다.
기존 파지 모듈은 비교용으로 보존합니다. 연결 제약은 여전히 가상 파지이며 마찰 파지가 아닙니다.
현재 연결 방식에서는 천과 손·두 손가락 사이 충돌을 제외하고, 놓을 때 집게가 열린 후
가상 연결을 해제합니다. 테이블과 천 자체 충돌은 유지합니다.
설치된 PhysX의 스키마·테스트와 [NVIDIA attachment 문서](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/latest/dev_guide/deformables/omniphysics_deformable_schema.html#attachments)를 참고했습니다.

## 같은 조건으로 비교

```powershell
& C:\IsaacLab\isaaclab.bat -p "C:\cloth-folding-rl\scripts\grasp\grasp_stability_demo.py" --video --picker_backend attachment --viz kit presets=isaacsim_physx
```

기존 강제 보정 방식과 비교하려면 `--picker_backend projection`을 사용합니다.
출력은 프로젝트 안의 `C:\cloth-folding-rl\videos\grasp_stability\실행시각\`에 저장합니다.
`--video_dir`로 저장 위치를 바꿀 수 있습니다.

- MP4: 전체 동작 검사와 정지 안정성을 모두 통과한 집기·정지 유지·놓기 영상에만 저장.
- `observation.csv`: 정지 유지 중 보정 전/실제 자유 정점 속도와 파지 오차.
- `observation.json`: 마지막 25% 구간의 RMS 속도, 형상 위치 변동 RMS, 최대 파지 오차.

임시 수치 기준은 마지막 구간 RMS 속도 0.02m/s 미만, 형상 변동 RMS 2mm 미만,
파지 오차 5mm 미만입니다. 시각적 확인도 필요하며 이 기준 통과 전 접기를 재개하지 않습니다.
로봇 이동 도달·들기 검사의 PASS와 진동 안정성의 stable은 별개입니다.
둘 중 하나라도 실패하거나 실행 오류가 발생하면 MP4 인코딩 없이 프레임 버퍼를 폐기합니다.
