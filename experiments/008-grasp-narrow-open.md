# 008 좁게 열고 집기
2026-10-29 · 유민아 · grasp: physical

- 문제 → 아이디어: 007은 그리퍼를 80 mm로 열어야만 들어 올렸고, 천을 약 6.5 cm 폭으로 접어 쥐고 모서리에서 대각선 7.8 cm 안쪽을 집음 (교수님 피드백: 천을 많이 집으면 접은 모양이 나빠짐) -> 30~40 mm만 열고, 집게가 y로만 벌어지는 점을 이용해 x 방향으로 모서리에 더 붙여서 집기. 메시를 더 촘촘하게 하고, 테이블 마찰을 현실 쪽으로 올려도 되는지 같이 확인
- 바꾼 것: 조합 실험. 1차 12회(조합마다 1번) + 2차 반복(1차 상위 3개 × 5번, 천 시작 위치 ±1 cm 흔들기)
  - 열린 손가락 간격 30 / 40 mm
  - 메시 해상도 edge_refinement 32 / 48 / 64 (정점 간격 6.25 / 4.2 / 3.1 mm, 수렴 확인 겸)
  - 테이블 마찰 0.03 / 0.3
  - 집는 점: x는 패드 여유(15 mm)만, y는 간격/2 + 15 mm (007은 대각선 위). 30 mm 기준 모서리에서 42 → 34 mm
- 고정 조건과 한계: PhysX (`physics=physx`). 누르는 깊이 0, 두께 3 mm, 굽힘 강성 ×1, 밀도·감쇠는 007과 동일. 손가락-천 마찰 1.5는 파지가 되도록 정한 값이고 실측하지 않아 현실보다 높을 수 있음. 패드 반폭 1 cm는 추정값. 천 높이(settle_gap)는 테이블이 중심 기준 직육면체라고 가정해 계산
- 판정 기준: #14 제안값 (들림: 집은 지점 20 mm 이상 6초 유지 / 품질: 모서리가 그리퍼 중심에서 3 cm 이내 / 반복: 5번 중 4번 이상). #14 확정 전
- 새로 재는 것: 모서리-그리퍼 거리, 빨려 들어간 천 폭(열린 간격 - 닫은 뒤 간격), 천이 가라앉은 높이(충돌 두께 확인용)
