# 직사각형 접기 시연

한 그리퍼로 로봇 가까운 변의 두 모서리를 반대편 변의 대응 모서리로 순서대로 옮깁니다.
단일 정점을 PhysX 연결 제약으로 잡으며, 대각선 삼각형 접기는 수행하지 않습니다.
기존 A 예제와 실험 파일은 보존합니다.

## 실행

Isaac Lab과 PhysX가 설치된 환경에서 실행합니다. 영상 저장 패키지가 없으면 프로젝트의
별도 의존성 폴더에 먼저 설치합니다. 이 폴더는 Git에서 제외됩니다.

```powershell
& C:\IsaacLab\_isaac_sim\python.bat -m pip install --target C:\cloth-folding-rl\scripts\grasp\video_dependencies -r C:\cloth-folding-rl\scripts\grasp\requirements-video.txt
```

```powershell
& "C:\cloth-folding-rl\scripts\grasp\run_rectangular_fold.ps1"
```

위치·각도를 바꿀 때:

```powershell
& "C:\cloth-folding-rl\scripts\grasp\run_rectangular_fold.ps1" -ClothX 0.48 -ClothY -0.08 -ClothYawDeg 10
```

직접 실행:

```powershell
& C:\IsaacLab\isaaclab.bat -p "C:\cloth-folding-rl\scripts\grasp\rectangular_fold_demo.py" --viz kit presets=isaacsim_physx
```

영상은 기본으로 캡처하되 **최종 접기 성공 시에만 MP4로 저장**합니다. `--no_video`로 캡처를 끌 수 있습니다.
실패·실행 오류·중단 시 프레임 버퍼는 파일 인코딩 없이 폐기하며 수치 기록만 남깁니다.
`--lift_height`, `--bend_stiffness`, `--settle_seconds`, `--success_distance`, `--seed`를 조절할 수 있습니다.
사용자 요청으로 기본 설정을 다음과 같이 확대·변경했습니다.

| 설정 | 이전 집기/접기 기준 | 현재 접기 기본값 |
|---|---:|---:|
| 천 크기 | 0.20 × 0.20m | 0.30 × 0.30m |
| 테이블 가로·세로 | 1.3 × 0.5m | 1.5 × 0.9m |
| 메시 refinement | 8 | 32 |
| 물리·표시 두께 | 1mm | 3mm |
| 굽힘 강성 계수 | 2e6 | 약 185.19 |
| Young 탄성계수 | 1e6 | 약 66666.67 |
| 체적 밀도 | 1000kg/m³ | 약 333.33kg/m³ |
| 들어 올리는 높이 | 0.08m | 0.12m |

`refinement`는 한 변의 정점 개수가 아니라 메시 최대 변 길이를 정하는 계수입니다.
실제로 생성된 정점 수는 실행 로그와 `result.json`의 `mesh_node_count`에 기록합니다.
천 중심은 로봇의 접근 여유를 위해 (0.50, -0.05)m로 설정했습니다.
테이블 높이는 기존 설정을 유지합니다.
3mm 두께로 늘리면서 직전 1mm 부드러운 천과 면적당 질량·막 강성을 비슷하게 유지하도록
밀도와 Young 탄성계수를 조절했습니다. 굽힘 강성 계수는 두께 보정에 더해 1/4로 낮춰
놓은 모서리가 말려 올라오는 현상을 줄였습니다.
PhysX의 유효 굽힘 강성이 두께의 세제곱에 비례하는 점을 반영했습니다.
[NVIDIA 물성 설명](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.3/dev_guide/deformables_beta/deformable_beta.html#material-limitations)을 참고했습니다.
각 항목은 `--cloth_size`, `--table_length`, `--table_width`, `--mesh_refinement`,
`--cloth_thickness`, `--cloth_density`, `--bend_stiffness`, `--youngs_modulus` 옵션으로 변경할 수 있습니다.
`towel_visual.py`는 시뮬레이션 정점을 따라 앞·뒤·옆면이 닫힌 3mm 표시 메시를 만들고,
부드러운 정점 법선과 반복되는 수건 섬유 색상·노멀 텍스처를 적용합니다.
표시용 겉면은 물리 정점 상태를 덮어쓰거나 추가 물리 충돌체를 만들지 않습니다.
텍스처는 `assets/materials/towel/`에 자동 생성합니다.
집기 안정성이 접기 성공을 보장하지는 않습니다.

## 모서리와 성공 판정

기존 프로젝트의 `scripts/corner_tracking/cloth_corner_tracker.py`를 가져와 사용합니다.
초기 천에서 모서리 정점 4개를 감지하고, 접는 동안에는 정점 번호를 유지하며 현재 좌표를 읽습니다.
네 모서리를 천 둘레 순서로 정렬해 로봇에 가까운 변을 선택하고, 반대편 변과 두 쌍을 만듭니다.
첫 번째 모서리를 놓은 후 두 번째 모서리의 현재 좌표로 다시 접근합니다.
목표 모서리 좌표도 옮기기·내려놓기 구간마다 새로 읽습니다.
모서리를 수직으로 든 뒤 수평으로 끌기보다, 접는 선 위로 반원 궤적을 따라 넘깁니다.
가상 파지 연결과 집게 접촉이 충돌하지 않도록 천과 손·두 손가락 사이의 충돌만 제외합니다.
테이블 접촉, 천 자체 충돌, 로봇의 나머지 접촉은 유지합니다.
내려놓을 때는 집게를 먼저 완전히 열고 나서 가상 연결을 해제합니다.
두 모서리를 놓고 안정화한 뒤 2cm 기준을 벗어난 쌍이 있으면 현재 오차가 가장 큰
모서리만 낮은 궤적으로 다시 맞춥니다. 보정은 최대 두 번이며, 보정 후에도 기준을
벗어나면 실패로 기록하고 영상을 저장하지 않습니다.

두 번 놓기·그리퍼 후퇴·정지 대기까지 마친 시점의 **3차원 유클리드 거리**를 측정합니다.
두 쌍 모두 0.02m 이하일 때만 `success=true`입니다.
이 조건은 이번 시연용 임시 기준이며, 천 전체의 평탄도·겹침 면적은 별도로 확인해야 합니다.

## 출력

프로젝트 안의 `C:\cloth-folding-rl\videos\rectangular_fold\실행시각\`에 저장합니다.
`--video_dir`로 저장 위치를 바꿀 수 있습니다.

- `config.json`: 초기 위치·각도·시드·물성·실행 옵션.
- `rectangular_fold_0000.mp4`: 성공한 전체 시연에만 저장, 640×480, 약 30 FPS.
- `result.json`: 성공 여부, 두 쌍의 거리, 최종 모서리 좌표·속도, 보정 횟수, 정점 번호와 대응 관계. 실행 오류도 기록.
- `steps.csv`: 시간, 동작 단계, 가상 파지 여부, 두 쌍의 거리.
- `demonstration.npz`: 성공한 실행에만 저장하는 시연 배열. 동작, 관절 위치, 모서리 좌표, TCP 등.

실패한 실행은 성공 시연 데이터에 포함하지 않습니다. 원인 분석용 JSON·CSV만 유지하고 MP4는 저장하지 않습니다.
모방 학습용 최종 저장 규격인 '2번 항목'은 아직 공유받지 않았으므로 NPZ는 임시 규격입니다.
강제 종료 시 메모리에 쌓인 영상과 데이터는 저장되지 않을 수 있습니다.

현재 파지는 접촉 마찰 기반이 아니라 단일 정점을 물리 솔버 내부의 Xform 연결 제약으로 잡습니다.
정점을 매 스텝 강제로 덮어쓰던 방식은 요동이 확인되어 비교용으로만 남겼습니다.
집기·정지 유지·놓기 진단은 [가상 파지 안정성](README_grasp_stability.md)을 참고하세요.
추적기 또한 기존 PCA 방식이므로 회전된 정사각형에서 실제 모서리를 정확히 골랐는지
반복 평가 때 확인해야 합니다. 성공률은 한 번의 실행으로 판단하지 않습니다.

## 실행 기록

이전 20cm·굽힘 강성 2e6 기준 실행은 두 번의 집기·이동·해제와 영상 저장을 완료했으나,
최종 모서리 거리가 약 19.2cm와 18.7cm여서 접기는 실패했습니다.
실패한 실행에서 학습용 `demonstration.npz`는 생성하지 않았습니다.
확대·연화 설정 결과는 별도 실행 폴더에 저장합니다.

2026-10-30: 솔버 내부 단일 정점 연결 방식으로 교체한 뒤, 확대·연화 기본 설정에서
전체 두 모서리 집기·반원 이동·놓기·후퇴를 완료했습니다.
최종 3차원 거리는 1.928mm, 0.965mm로 두 쌍 모두 2cm 기준을 통과했습니다.
당시 실행 폴더는 `output/rectangular_fold/20261030_024609_350060`이며 MP4, 결과 JSON,
단계별 CSV, 성공 시연 NPZ를 저장했습니다. 마지막 영상 프레임에서 직사각형으로 겹쳐진
형상을 확인했습니다. 이는 기본 초기 조건에서 1회 성공한 결과이며 위치·각도 변화에 대한
성공률 평가는 아직 수행하지 않았습니다.

두께·밀도 확대 후 검증: 3mm 두께·refinement 32에서 실제 물리 정점 1,089개로 생성됐습니다.
첫 설정의 최종 거리 2.53cm/1.52cm, 연화 설정의 2.41cm/3.26cm 실행은 실패로 기록됐고
해당 실행 폴더에 MP4가 생성되지 않는 것을 확인했습니다.
가상 집게 접촉 제외와 좌표 추적 기반 보정 1회 후 최종 1.069cm/1.978cm로 성공했습니다.
새 영상은 `videos/rectangular_fold/20261030_031738_152536/rectangular_fold_0000.mp4`입니다.
최종 정점 RMS 속도는 약 0.00434m/s이며, 영상 저장과 성공 시연 NPZ 생성을 확인했습니다.
한 번의 실행 결과이고 두 번째 쌍은 2cm 한계에 가까우므로 반복 성공률은 별도로 평가해야 합니다.

`successful_video.py`는 전체 실행의 성공 판정까지 프레임만 모으고, 성공 시에만
환경 종료 시점에 MP4 인코더를 호출합니다. 실패·중단 시에는 인코딩을 호출하지 않습니다.
저장 분기 단위 검사 2개와 실제 접기 실패 실행의 MP4 미생성을 검증했습니다.
